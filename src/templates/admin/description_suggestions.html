Suggestions sur des Descriptions

Cette page vous permet de visualiser les suggestions d'imputation sur les descriptions.
Les suggestions sont basées sur les mots clés présents dans les descriptions des personnages. On cherche des correspondances entre les questions et les descriptions. Il n'y a que des suggestions de réponses "Oui".
Vous pouvez définir un seuil de nombre de personnages dont la description doit contenir le mot clé (ex : si le seuil est de 3, alors il faut que le mot clé soit présent dans la description d'au moins 3 personnages pour que les suggestions soient affichées).
